1. CORE DESKTOP PROCESSES & DETAILED DECORATIVE CONFIGURATIONS
================================================================================

A. HYPRLAND COMPOSITOR (v0.55.0+)
   * Purpose: Wayland display server, window manager, and native compositor.
   * Lua Engine Configuration Interface: Uses a custom Lua-based configuration parser
     (global namespace 'hl'). All window rules, keybindings, customizations, and
     environment settings are handled inside the Lua modular structure.
   * Required Window Rules (~/.config/hypr/conf/windowrules.lua):
     - Modal dialogues forced to tile: `hl.window_rule({ match = { modal = true }, tile = true })`
     - XWayland floating windows tiled: `hl.window_rule({ match = { xwayland = true, float = true }, tile = true })`
     - Scratchpad class auto-floating: `hl.window_rule({ match = { class = "scratchpad" }, float = true, workspace = "special:scratchpad" })`
     - Smart Gaps borderless single window: `hl.window_rule({ match = { workspace = "w[tv1]", float = false }, border_size = 0, rounding = 0 })`
   * Required Workspace Rules (~/.config/hypr/conf/workspaces.lua):
     - Smart Gaps inner/outer gap removal: `hl.workspace_rule({ workspace = "w[tv1]", gaps_in = 0, gaps_out = 0 })`
   * Reload Command: Triggers instant, seamless configuration reloading at runtime via the Lua engine:
     - `SUPER + R` (recompiles and applies keybindings, workspace maps, and layout trees).

B. WAYBAR STATUS BAR (v0.10+)
   * Purpose: Highly customizable desktop status bar showing workspaces, networks, tray, hardware metrics, and active notifications.
   * Configuration File (~/.config/waybar/config):
     - Configured with a "top" layer, centered clock module, left workspaces module, right system group tray, and the dynamic recorder widget.
     - Active module tracking "custom/recording" added to "modules-left" to dynamically align it as a left-side dynamic pill/island.
     - Configured to reload and trigger instant redraws instantly upon receiving user signal 8 (`"signal": 8`).
   * Styling System (~/.config/waybar/style.css):
     - Uses Vanilla CSS utilizing glassmorphism and tailormade color gradients.
     - Blinking recorder styling class `#custom-recording` utilizing keyframe animations to pulse between semi-transparent and bright solid red borders.

C. ROFI UTILITY FOR WAYLAND & CLIPBOARD INTERFACE
   * Purpose: Menu selector, interactive prompt launcher, and custom clipboard viewer.
   * Native Package Requirement: Must use wayland-native rofi (e.g., `rofi-lbonn-wayland-git`) to support clipboard interaction and correct cursor tracking under Hyprland.
   * Rofi Configurations:
     - Main Launcher (~/.config/rofi/simple.rasi): Employs a premium dark aesthetic with neon teal highlights (#00ffb3).
     - Dedicated Clipboard Theme (~/.config/rofi/clipboard.rasi): Single-column 850px wide layout with disabled icons, optimized for previewing multi-line clipboard text and code snippets.
     - Dynamic Compact overrides: Start menu is resized dynamically to a width of 450px with a single column and 3 compact lines using:
       `-theme-str 'window { width: 450px; } listview { columns: 1; lines: 3; }'`

D. CLIPBOARD MANAGER (cliphist)
   * Purpose: Persistent Wayland clipboard manager storing text, code snippets, and image history.
   * Daemon Script (~/.config/hypr/scripts/clipboard-daemon.sh):
     - Watches standard clipboard text/images (`wl-paste --watch cliphist store`) and primary mouse selection.
     - Autostarted via `conf/autostart.lua`.
   * Keybinding (<kbd>SUPER + V</kbd>):
     - Triggers `cliphist list | rofi -dmenu -i -p '📋 Clipboard' -theme ~/.config/rofi/clipboard.rasi | cliphist decode | wl-copy`.
   * Storage: Persisted on disk across system reboots at `~/.cache/cliphist/db` (capacity: 750 items).

E. KITTY TERMINAL EMULATOR
   * Purpose: Native GPU-accelerated terminal emulator.
   * Requirements:
     - Font family: `JetBrainsMono Nerd Font` for accurate display of icons and developer syntax.
     - Font size: Bold 12pt default.

F. HYPRLOCK LOCK SCREEN
   * Purpose: Desktop lock screen utility.
   * Styling Configurations (~/.config/hypr/hyprlock.conf):
     - Customized clock spacing using tight Pango text padding markup.
     - Password text input dots size optimized to perfectly match system aesthetic constraints.
     - Integrated a dynamic glassmorphic battery status capsule driven by a custom monitoring shell script (`~/.config/hypr/scripts/battery.sh`).

G. HYPRPAPER WALLPAPER DAEMON
   * Purpose: Native utility to pre-load and swap desktop screen wallpaper canvases.
   * Requirements: Requires `~/.config/hypr/hyprpaper.conf` to preload background images on compositor startup.

H. DUNST NOTIFICATION DAEMON (v1.13+)
   * Purpose: Lightweight, highly customizable notification daemon.
   * Note: Active notification daemon (replaces `mako` and `swaync`). Autostarted inside `conf/autostart.lua`.

I. POLICYKIT (POLKIT) AUTHENTICATION AGENT (hyprpolkitagent)
   * Purpose: Handles privilege elevation requests for GUI applications.
   * Note: Active authentication agent is `hyprpolkitagent`. Autostarted inside `conf/autostart.lua`.

2. UTILITIES & GRADIENT SYSTEM MECHANICS
================================================================================

A. WF-RECORDER (Arch: `sudo pacman -S wf-recorder`)
   * Purpose: Native Wayland screen capture utility that pipes the Hyprland screencopy buffers directly into containerized video streams.
   * Crucial Process Management: Must be closed strictly using the standard SIGINT signal (`kill -2 <PID>`). Terminating using SIGKILL (`kill -9`) corrupts the MP4 container wrapper and leaves the recorded video corrupted and unplayable.

B. SLURP (Arch: `sudo pacman -S slurp`)
   * Purpose: Desktop region selector that outputs Wayland coordinates (`X,Y WxH`).

C. GRIM (Arch: `sudo pacman -S grim`)
   * Purpose: Direct Wayland screenshot capture utility.

D. LIBNOTIFY / NOTIFY-SEND (Arch: `sudo pacman -S libnotify`)
   * Purpose: Standard desktop notification system.

E. WL-CLIPBOARD & CLIPHIST (Arch: `sudo pacman -S wl-clipboard cliphist`)
   * Purpose: Command-line copy/paste utilities for Wayland and persistent clipboard history manager.

F. PAMIXER (Arch: `sudo pacman -S pamixer`)
   * Purpose: Command-line volume mixer for PulseAudio/PipeWire.

G. BRIGHTNESSCTL (Arch: `sudo pacman -S brightnessctl`)
   * Purpose: Command-line tool to control device brightness.

H. HYPRSUNSET (Arch: `sudo pacman -S hyprsunset`)
   * Purpose: Blue light filter and color temperature tool for Hyprland (4500K).

4. PYTHON 3 CONTROLLERS & SERVICES
================================================================================

* Python 3.x is required as the core script runtime executor.
* Core Helper: `recording_status.py` (~/.config/waybar/scripts/recording_status.py)
  - Fetches active User ID directly from the Linux Kernel via `os.getuid()` to dynamically monitor active `wf-recorder` processes.
  - Measures duration by comparing epoch timestamp of `/tmp/wf-recorder.pid`.

5. SYSTEM STATE FLOWS & SCRIPT INTEGRATIONS
================================================================================

A. KEYBINDING TRIGGERS:
   - `SUPER + SHIFT + S`: Executes `~/.config/hypr/scripts/screen_record.sh`
   - `SUPER + V`: Opens Rofi Clipboard History (`cliphist list | rofi -dmenu ...`)
   - `SUPER + U`: Toggles Special Workspace (Scratchpad)
   - `SUPER + SHIFT + U`: Moves focused window to Scratchpad
   - `SUPER + SHIFT + ENTER`: Toggles/launches Scratchpad Kitty terminal

6. RESTORATION AND SETUP INSTRUCTIONS
================================================================================

A. INSTALL ALL REQUIRED PACKAGES:
   `sudo pacman -S hyprland waybar kitty hyprlock hyprpaper wf-recorder slurp grim libnotify ttf-jetbrains-mono-nerd rofi wl-clipboard cliphist pamixer brightnessctl hyprsunset dunst hyprpolkitagent`

B. ENSURE SCRIPTS ARE FULLY EXECUTABLE:
   `chmod +x ~/.config/hypr/scripts/screen_record.sh`
   `chmod +x ~/.config/hypr/scripts/battery-notification.sh`
   `chmod +x ~/.config/hypr/scripts/device-notifier.sh`
   `chmod +x ~/.config/hypr/scripts/clipboard-daemon.sh`
   `chmod +x ~/.config/waybar/scripts/recording_status.py`

C. APPLY THE LUA CONFIGURATION:
   - Reload Hyprland configuration: Press `SUPER + R` (or run `hyprctl reload`)
