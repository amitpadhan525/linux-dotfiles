A. HYPRLAND COMPOSITOR (v0.55.0+)
   * Purpose: Wayland display server, window manager, and native compositor.
   * Lua Engine Configuration Interface: Uses a custom Lua-based configurations parser
     (global namespace 'hl'). All window rules, keybindings, customizations, and
     environment settings are handled inside the Lua modular structure.
   * Required Window Rules (~/.config/hypr/conf/windowrules.lua):
     - Modal dialogues forced to tile: `hl.window_rule({ match = { modal = true }, tile = true })`
     - XWayland floating windows tiled: `hl.window_rule({ match = { xwayland = true, float = true }, tile = true })`
   * Reload Command: Triggers instant, seamless configuration reloading at runtime via the Lua engine:
     - `SUPER + R` (recompiles and applies keybindings, workspace maps, and layout trees).

   * Styling System (~/.config/waybar/style.css):
     - Uses Vanilla CSS utilizing glassmorphism and tailormade color gradients.
     - Blinking recorder styling class `#custom-recording` utilizing keyframe animations to pulse between semi-transparent and bright solid red borders.

2. UTILITIES & GRADIENT SYSTEM MECHANICS
================================================================================

A. WF-RECORDER (Arch: `sudo pacman -S wf-recorder`)
   * Purpose: Native Wayland screen capture utility that pipes the Hyprland screencopy buffers directly into containerized video streams.
   * Crucial Process Management: Must be closed strictly using the standard SIGINT signal (`kill -2 <PID>`). Terminating using SIGKILL (`kill -9`) corrupts the MP4 container wrapper and leaves the recorded video corrupted and unplayable.
   * Multi-Mode Operation:
     - Fullscreen Recording: Captures the whole output screen: `wf-recorder -f <SAVE_PATH>`
     - Area/Region Recording: Selects coordinate rectangles: `wf-recorder -g "<GEOMETRY>" -f <SAVE_PATH>`

B. SLURP (Arch: `sudo pacman -S slurp`)
   * Purpose: Desktop region selector that outputs Wayland coordinates (`X,Y WxH`).
   * Requirements: Pipes the geometry directly into `wf-recorder -g` and outputs exit code 1 if selection is cancelled by pressing ESC.

C. GRIM (Arch: `sudo pacman -S grim`)
   * Purpose: Direct Wayland screenshot capture utility.

D. LIBNOTIFY / NOTIFY-SEND (Arch: `sudo pacman -S libnotify`)
   * Purpose: Standard desktop notification system. Send status notifications on start/stop and provides click-action prompts and save paths.

E. WL-CLIPBOARD (Arch: `sudo pacman -S wl-clipboard`)
   * Purpose: Command-line copy/paste utilities for Wayland (provides `wl-copy`). Used by screenshots to copy raw image data directly to system clipboard.

F. PAMIXER (Arch: `sudo pacman -S pamixer`)
   * Purpose: Command-line volume mixer for PulseAudio/PipeWire. Used by keybindings to control sound level and muting.

G. BRIGHTNESSCTL (Arch: `sudo pacman -S brightnessctl`)
   * Purpose: Command-line tool to control device brightness. Used by keybindings to adjust monitor screen brightness.

H. HYPRSUNSET (Arch: `sudo pacman -S hyprsunset`)
   * Purpose: Blue light filter and color temperature tool for Hyprland, used to set temperature to 4500K dynamically.

4. PYTHON 3 CONTROLLERS & SERVICES
================================================================================

* Python 3.x is required as the core script runtime executor.
* Core Helper: `recording_status.py` (~/.config/waybar/scripts/recording_status.py)
  - Process Owner Strategy: Rather than relying on unreliable environmental user strings (`os.getenv("USER")`), it fetches the active User ID directly from the Linux Kernel via `os.getuid()` to dynamically monitor active `wf-recorder` processes.
  - Duration Parser: Measures the active recording duration by comparing current epoch time with the creation/modification timestamp of the temporary file (`/tmp/wf-recorder.pid`):
    `elapsed = int(time.time() - os.path.getmtime("/tmp/wf-recorder.pid"))`
  - Output Interface: Serializes a formatted JSON dictionary directly to standard stdout output for Waybar:
    `{"text": "●  REC  00:05", "class": "recording", "tooltip": "Recording active. Click to Stop."}`
  - Pulsing Mechanism: Automatically triggers dot pulsing on and off by calculating: `elapsed % 2 == 0`.
  - Auto-Hidden State: If `wf-recorder` is not running, it outputs `{"text": "", "class": "hidden"}` which instantly hides the Dynamic Island pill from Waybar completely.

5. SYSTEM STATE FLOWS & SCRIPT INTEGRATIONS
================================================================================

A. KEYBINDING TRIGGERS:
   - When the user presses `SUPER + SHIFT + S` hotkey, `/home/amit/.config/hypr/scripts/screen_record.sh` is executed.

B. SCREEN RECORDER CORE FLOW (screen_record.sh):
   1. If `wf-recorder` is currently active:
      * Gracefully shuts down `wf-recorder` (`kill -2`).
      * Waits for the process to fully close and flush video buffers.
      * Prompts the user to save as a custom name using an empty, compact Rofi text prompt.
      * If user inputs a name, renames the output file to `Name.mp4`. If left empty or cancelled, defaults to saving with the timestamp `recording_YYYY-MM-DD_HH-MM-SS.mp4`.
      * Cleans up all temporary PIDs.
      * Fires the Waybar redraw trigger signal (`pkill -RTMIN+8 waybar`).
      * Triggers notify-send with the final save path.
   2. If `wf-recorder` is NOT currently active:
      * Launches the compact Rofi menu with `Record Fullscreen` highlighted as the first choice.
      * If `Record Fullscreen` is selected: Launches `wf-recorder -f` to capture the whole monitor.
      * If `Record Area` is selected: Triggers `slurp` to let the user select a custom area, then launches `wf-recorder -g` to capture that specific region.
      * Saves PID to `/tmp/wf-recorder.pid` and the filepath to `/tmp/wf-recorder.path`.
      * Instantly refreshes Waybar (`pkill -RTMIN+8 waybar`) to display the dynamic recording indicator.
      * Sends a desktop startup notification.
