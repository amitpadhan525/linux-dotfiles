Linux dotfiles install guide

This repo contains Arch Linux dotfiles and helper scripts for a Hyprland-based
Wayland desktop. The installer links the configs in this repo into your home
directory and installs the packages needed for the desktop to work.

1. Prerequisites

Before you run the installer, make sure you are on Arch Linux or an Arch-based
system and have network access.

Install the basic build tools needed for the installer and for AUR packages:

    sudo pacman -Syu --noconfirm git base-devel

2. Clone the repo

    git clone https://github.com/amitpadhan525/linux-dotfiles.git
    cd linux-dotfiles

3. Run the installer

The default install script does three things:
it updates packages, installs the required desktop packages, and links the
configs from this repo into ~/.config and your home directory.

    chmod +x install.sh
    ./install.sh

The script will ask before it makes changes. It also tries to back up existing
config folders before replacing them.

4. Useful installer flags

    ./install.sh --help
    ./install.sh -y              non-interactive install
    ./install.sh -d              dry run, no changes written
    ./install.sh -c              configs only, skip package install
    ./install.sh -p              packages only, skip linking configs
    ./install.sh -n              skip backup creation
    ./install.sh -f              force through some checks

5. What the installer installs

The installer pulls in the core Hyprland desktop stack, bar, terminal, file
manager, notifications, wallpaper tools, audio tools, clipboard helpers,
fonts, and session services such as:

    hyprland hyprpaper hyprlock hyprsunset waybar rofi-wayland kitty thunar
    dunst mako nwg-dock-hyprland nwg-look pipewire wireplumber pamixer playerctl
    pavucontrol libpulse brightnessctl networkmanager nm-connection-editor
    blueman acpi upower slurp grim wf-recorder wl-clipboard jq python
    libnotify hyprpolkitagent gnome-keyring xsettingsd network-manager-applet
    xdg-desktop-portal-hyprland xdg-desktop-portal-gtk pipewire-pulse
    ttf-jetbrains-mono-nerd noto-fonts noto-fonts-emoji ttf-font-awesome
    ttf-inter ttf-outfit

It also installs AUR packages through your AUR helper if one is available.
If no helper is installed, the script can bootstrap one after confirming that
git and base-devel are present.

6. Manual install path

If you want to install packages by hand, use the package list above and then
link the configs from this repo into the matching locations under ~/.config.

Typical config paths are:

    ~/.config/hypr
    ~/.config/waybar
    ~/.config/rofi
    ~/.config/kitty
    ~/.config/dunst
    ~/.config/mako
    ~/.config/nwg-dock-hyprland
    ~/.config/nwg-look
    ~/.config/hyprfm
    ~/.config/gtk-3.0
    ~/.config/gtk-4.0
    ~/.config/xsettingsd
    ~/.config/systemd/user

The installer also links these home files:

    ~/.bashrc
    ~/.bash_profile
    ~/.gitconfig

7. After installation

Log out and choose the Hyprland session from your display manager.
Then check your monitor settings in ~/.config/hypr/conf/monitors.lua and
review the keybindings in README.md if you want to customize the desktop.

8. Roll back if needed

If you want to undo the install, remove the symlinks and restore any backups
you created from ~/.config/backups.
