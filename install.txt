🌌 ASTRAEUS HYPRLAND - TERMINAL INSTALLATION MANUAL & bluePRINT
================================================================================
This is a lightweight, terminal-friendly reference manual for deploying the 
Astraeus Environment. Keep this file handy if you are executing configurations 
manually or from a headless TTY session.

--------------------------------------------------------------------------------
1. PRE-INSTALLATION SYSTEM SYNCHRONIZATION
--------------------------------------------------------------------------------
Before executing any script, ensure your Arch Linux system databases are fully
synchronized and essential development headers/runtimes are present:

    sudo pacman -Syu --noconfirm base-devel git

--------------------------------------------------------------------------------
2. AUTOMATED DEPLOYMENT ORCHESTRATION (install.sh)
--------------------------------------------------------------------------------
The most reliable deployment path is utilizing the robust "install.sh" script:

    git clone https://github.com/amitpadhan525/linux-dotfiles.git
    cd linux-dotfiles
    chmod +x install.sh
    ./install.sh

--------------------------------------------------------------------------------
3. COMMAND-LINE OPTION FLAGS (Advanced Setup)
--------------------------------------------------------------------------------
For administrators, the installer can be configured with specific flags:

    ./install.sh --help               - Display help banner and CLI flags.
    ./install.sh -y                   - Non-interactive (bypasses prompt checks).
    ./install.sh --dry-run            - Safe simulation without disk writes.
    ./install.sh --configs-only       - Maps symbolic links only (skips pacman).
    ./install.sh --packages-only      - Provision package dependencies only.
    ./install.sh --no-backup          - Bypasses backup and overrides configs.

--------------------------------------------------------------------------------
4. THE ATOMIC BACKUP SYSTEM & DIRECT OVERWRITING
--------------------------------------------------------------------------------
* AUTOMATED SAFE BACKUP (Default Behavior):
  If the installer detects pre-existing configuration folders (such as ~/.config/hypr),
  it automatically compresses them into a tarball backup before deploying Astraeus:
  
      Destination: ~/.config/backups/astraeus_backup_<mod>_<timestamp>.tar.gz

  If the compression fails, the script halts instantly to protect your data.

* HARD OVERWRITE MODE (Bypass Backup):
  If you wish to do a clean slate installation and avoid creating backup files,
  pass the '--no-backup' (or '-n') flag to the installer:
  
      ./install.sh --no-backup

--------------------------------------------------------------------------------
5. MANUAL ROLLBACK & RESTORATION GUIDE
--------------------------------------------------------------------------------
If you ever want to revert your system and restore your exact pre-Astraeus
configurations, execute these terminal commands:

    # 1. Remove symbolic links pointing to the Astraeus repository
    rm -rf ~/.config/{hypr,waybar,rofi,kitty}

    # 2. Extract your compressed backups directly back into your config path
    tar -xzf ~/.config/backups/astraeus_backup_hypr_*.tar.gz -C ~/.config/
    tar -xzf ~/.config/backups/astraeus_backup_waybar_*.tar.gz -C ~/.config/
    tar -xzf ~/.config/backups/astraeus_backup_rofi_*.tar.gz -C ~/.config/
    tar -xzf ~/.config/backups/astraeus_backup_kitty_*.tar.gz -C ~/.config/

--------------------------------------------------------------------------------
6. COMPLETE ECOSYSTEM DEPENDENCY DIRECTORY (Package List)
--------------------------------------------------------------------------------
If you prefer not to use the automated script, you can install the exact package
stack using the pacman command:

    sudo pacman -S --needed --noconfirm \
        hyprland hyprpaper hyprlock hyprsunset waybar rofi-wayland kitty thunar \
        mako pipewire wireplumber pamixer pavucontrol libpulse brightnessctl \
        networkmanager nm-connection-editor blueman acpi upower slurp grim \
        wl-clipboard jq python libnotify polkit-kde-agent gnome-keyring \
        xsettingsd ttf-jetbrains-mono-nerd noto-fonts noto-fonts-emoji \
        ttf-font-awesome base-devel git

--------------------------------------------------------------------------------
7. MANUAL SCRIPT PERMISSIONS ENFORCEMENT
--------------------------------------------------------------------------------
Astraeus relies on internal scripting modules. If configuring manually, ensure
executable execution bits are correctly registered:

    chmod +x ~/.config/hypr/scripts/*.sh
    chmod +x ~/.config/waybar/scripts/*.sh
    chmod +x ~/.config/waybar/scripts/*.py

--------------------------------------------------------------------------------
8. POST-INSTALLATION ADJUSTMENTS
--------------------------------------------------------------------------------
1. Adjust Monitors: Edit '~/.config/hypr/conf/monitors.lua' for displays.
2. Load Compositor: Log out and select the "Hyprland" session from your Login DM.
3. System Console: Press 'Super + Enter' to open Kitty terminal.
4. Keybindings Guide: Open 'README.md' or use the keys below:
   * Super + D              - Open Application Grid (Rofi)
   * Super + E              - Open File Manager (Thunar)
   * Super + S              - Save Area Screenshot (Rofi Named)
   * Super + Shift + S      - Record Screen Selector (Region/Fullscreen)
   * Super + R              - Hot-Reload Compositor (Lua Engine)
   * Super + N              - Night Mode Toggle (Blue light control)
   * Super + Shift + L      - Lock Desktop Session (Hyprlock)
   * Super + Q              - Terminate Active Window
